# Spole-ikon

`spole-arcticons.svg` er eit forslag til Arcticons, ikkje sendt inn. Appfilter-oppføringar:

```xml
<item component="ComponentInfo{app.reelstack/app.reelstack.MainActivity}" drawable="spole"/>
<item component="ComponentInfo{app.reelstack.debug/app.reelstack.MainActivity}" drawable="spole"/>
```

Teikninga følgjer [Arcticons-rettleiinga](https://docs.arcticons.com/contribute/creating-icons): 48 × 48 px, kvit 1 px strek, avrunda endar og hjørne, ingen fyll. Merket er 27 × 38,25 px innanfor rektangelmalen 31 × 39 px. Forma er basert på Spole sitt merke med to filmruter i `spole_launcher_foreground.xml`, lese frå `C:/JellyBin/spole-launcher-link`; ingen kjeldefiler er endra. `SpoleIcons` er òg lesen som stilreferanse.

`spole-color.svg` er den flate fargeutgåva med Spole-lime på mørk flate. Appen har dei same banane i `ic_spole_arcticons.xml` og `ic_spole_brand.xml`; fargar for den flate utgåva ligg i `core/theme/SpoleArtwork.kt`. Ingen Arcticons-ikon er pakka inn i produksjonsappen. Arcticons sine ikon er CC BY-SA 4.0 og programkoden GPL-3.0; sjå [prosjektet](https://github.com/Arcticons-Team/Arcticons). Forslaget er førebudd for ikonprosjektet sin CC BY-SA 4.0-lisens; Spole-merket identifiserer Spole.
