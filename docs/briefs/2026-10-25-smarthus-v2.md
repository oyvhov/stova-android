## Designkjelde: Tunet

Tunet er brukaren sitt eige HA-dashbord.
- **Kloning:** `gh repo clone oyvhov/Tunet C:\CodexCaches\tunet-ref`, berre for lesing. Ikkje endre
  eller pushe noko der.
- **Kva du ser etter:** kortkomponentane, typografi, ikonbruk, tilstandsfargar, korleis lys, klima,
  straumpris, vêr, media og kamera er teikna, og oppsettet med storleikar.
- **Omsetjing:** overfør det til Stova sitt flate, dempa uttrykk. Stova har ingen glas eller blur,
  og brukar fargane i `core/theme/Tokens.kt`. Eksisterande skisse er §5.2: `Surface`-kort,
  16 dp hjørne, ikon i `Raised`-rute, stor verdi og liten etikett.
- **Målet:** kort som ser like gjennomarbeidde ut som Tunet på ein TV med D-pad.

## 1. Vel einingar (Legg til kort v2)

- **Robust lasting:** `HaConnection.states()` gir tom liste når sokkelen ikkje er `CONNECTED`, og
  `AddCardFlow` prøver berre éin gong.
  - Vent på `CONNECTED` og last på nytt.
  - Vis skjelett under lasting.
  - Skil «ikkje kopla til» frå «ingen einingar».
- **Rom og namn frå registra** over WebSocket:
  - `config/area_registry/list`, `config/device_registry/list` og
    `config/entity_registry/list` (eller `…/list_for_display`).
  - Rommet er `entity.area_id` eller `device.area_id`.
  - Skjul einingar med `hidden_by`/`disabled_by` og `entity_category` (config/diagnostic), med
    eit «Vis alle»-val.
- **Visning:**
  - Rutenett av einingsflisar: ikon etter domene/`device_class`, venleg namn, rom og
    noverande tilstand.
  - Gruppebrikker: Alle, Lys, Brytarar, Klima, Sensorar, Vêr, Media, Scener, Kamera, Straumpris,
    Gardiner/port, Lås.
  - Søk, og sortering på rom og så namn.
  - Merke på einingar som alt har kort.

## 2. Smarthus-sida v2

- **Overskrift:** «Smarthus», tilkoplingsstatus og ei roleg oppsummering (t.d. «3 lys på ·
  21,5° inne · 84 øre nå») frå einingane på dashbordet.
- **Seksjonar per rom** med overskrift. Ein valfri «Favorittar»-seksjon kjem først.
- **Kortstorleik per kort:** S (1×1), M (2×1) og L (2×2). Dette erstattar `wide: Boolean`.
  Migrer gamle `wide=true` til M med serialiseringsstandardar.
- **Korttypar,** alle med tydeleg tilstand og ikon. Lys skal «gløde» i dempa aksent når det er på.

| Type | Visning | OK | Venstre/høgre når fokusert | Meny |
|---|---|---|---|---|
| Lys | tilstand, lysstyrke-%, eventuelt farge/temperatur | av/på | lysstyrke ±10 % direkte | storleik, namn, ikon … |
| Brytar/vifte/input_boolean | av/på | av/på | – | |
| Klima | noverande temp stort, måltemp, modus | dialog | måltemp ±0,5 | |
| Sensor | verdi + eining, 24 t-sparkline i kortet | 24 t-graf | – | |
| Binærsensor | dør/vindauge/rørsle med ord («Open», «Lukka») | – | – | |
| Vêr | no + 5 dagar, via `weather.get_forecasts` med `return_response` (forecast-attributtet er fjerna i HA 2024.3+) | – | – | |
| Straumpris | Nordpool i dag/i morgon som søyler, noverande time markert, min/maks | graf | – | |
| Mediaspelar | kunst frå `entity_picture`, tittel/artist, spel/pause/neste, volum | spel/pause | volum | |
| Scene/skript | køyr, med kvittering | køyr | – | |
| Kamera | stillbilete i kortet, oppdatert kvart 10. s | fullskjerm (2 s) | – | |
| Gardin/port (`cover`) | open/lukka/% | opne/lukke/stopp-dialog | posisjon ±10 % | |
| Lås (`lock`) | låst/opa | stadfesting før endring | – | |

- **Meny / lang OK** på kort: Storleik, Flytt (venstre/høgre/opp/ned), Gi nytt namn, Vel ikon (eit
  lite utval Material-ikon), Vis på Heim (maks 3), Fjern.
  - Utvid `CardConfig` med `size`, `name: String?`, `icon: String?`, med standardverdiar for
    bakoverkompatibilitet.
- **Optimistisk UI** ved brytarar: vis ny tilstand straks, rull tilbake med ei roleg melding om
  tenestekallet feilar, og vis ventemerke.
- **Heim-brikkene** i toppfeltet (`HomeStatusChips`) får same ikon og formspråk som korta.
- **Barnemodus:** kun lesing, som i dag (`canControl`).

## 3. Test mot ekte Home Assistant («Test alt du vil»)

- **Emulator:** `emulator-5580` køyrer Stova debug, innlogga i brukaren sitt HA. Du kan styre han
  med `adb` (scrcpy-vindauget er ope; ikkje lukk det).
  - Installer berre `app.stova.debug` med `adb -s emulator-5580 install -r`.
  - Aldri `uninstall`, `pm clear` eller sletting av data: innloggingane skal stå.
- **Dashbord:** bygg eit realistisk dashbord på emulatoren med fleire lys, klima, sensorar,
  straumpris, vêr, media og kamera.
- **Styring:** skru eit par lys av og på og set dei tilbake til slik dei var. Endre ein måltemp og
  set han tilbake.
  - **Aldri** endre alarm, lås, garasjeport eller anna tryggleiksutstyr for verkeleg; berre les.
- **Skjermbilete:** ta dei med `adb exec-out screencap -p`, lagre i
  `C:\Launcher\.superpowers\ha-v2-*.png` og dei beste i `docs/images/ha-v2-*.png`. Sjå på dei sjølv
  og fiks det som ikkje er vakkert.
- **Aldri** bruk emulator-5560/-5562/-5564.

## Tillegg frå brukaren (25.10.2026, under arbeidet)

> «[Smarthus] bør vere i stil med TV Launcher-appen … denne appen vi lagar.»

- **Stil:** Smarthus skal sjå ut som ein naturleg del av Stova, ikkje som Tunet.
  - Tunet er kjelda til *kva* korta viser og kva dei kan gjere. Utsjånaden er Stova sin:
    same kortformspråk som medie- og appkorta på Heim, same fokusring (`focusOutline`, berre rundt
    kortflata), same typografi, same dempa fargar og same luft.
- **Tema:** bruk `MaterialTheme.colorScheme.primary` som aksent og `MaterialTheme.shapes` for hjørne.
  Då følgjer HA-korta dei nye utsjånadsvala (aksentfarge, hjørne), som ein annan agent legg inn i
  temaet.
