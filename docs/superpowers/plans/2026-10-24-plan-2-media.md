# Stova Plan 2 – Media frå Jellyfin og Emby · implementasjonsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Heimeskjermen viser Hald fram og Nyleg lagt til frå kvar Jellyfin-/Emby-konto i profilen, med hero, score og backdrop som bakgrunn. Titlar blir opna i Spole, og «Watch Next» frå andre appar ligg i ei eiga rad.

**Architecture:** Éin felles REST-klient for Jellyfin og Emby, med endepunkt-kandidatar som blir prøvde i rekkjefølgje (som Spole). `MediaRepository` sender først øyeblikksbiletet frå disk og oppdaterer så frå nettet. Radene kjem inn i `HomeViewModel` som `HomeRowSource`. Bilete går gjennom Coil 3 med OkHttp. Backdrop og hero blir styrte av fokus via `BackdropController`.

**Tech Stack:** Som Plan 1, pluss OkHttp 4.12.0, Coil 3.4.0 (`coil-compose`, `coil-network-okhttp`) og MockWebServer 4.12.0 (test).

**Spec:** `docs/superpowers/specs/2026-10-24-stova-launcher-design.md` (§5.1, §6, §7, §10)

## Global Constraints

- Alle Global Constraints frå Plan 1 gjeld.
- Jellyfin og Emby blir aldri blanda i same rad. Hald fram slår saman resume og neste episode berre innanfor same konto.
- Bilete blir alltid bedne om med `tag` og storleik: backdrop `maxWidth=1920&quality=80`, logo `maxWidth=600`, plakat `maxHeight=450&quality=90`, brei `maxWidth=640`.
- Ingen token i URL-ar, øyeblikksbilete eller loggar.
- Kunstformat: film i «Nyleg lagt til · Filmar» = plakat 132 × 198 dp. Alt anna = brei 248 × 139,5 dp. Framdriftsstrek 4 dp lime i botnen av breie kort.
- Nettverk: connect-timeout 4 s, read-timeout 8 s, og maks 10 s per konto per oppdatering.
- Spole-lenkja følgjer spesifikasjonen §7 nøyaktig: `spole://open?kind=jellyfin|emby&user=<id>&item=<id>&action=details|play`.

## Review Focus

1. **Serveren er nede eller utilgjengeleg utanfor heimen.** Forventa: bufra rader blir viste straks med «Fråkopla» i radoverskrifta. Ingen evig lasting, ingen tom skjerm. Test i oppgåve 5.
2. **Token utgått eller passord endra (HTTP 401).** Forventa: kontoen blir merkt «Logg inn på nytt» i Innstillingar → Kontoar og rada blir skjult. Andre kontoar blir ikkje påverka. Test i oppgåve 5.
3. **Episode utan eigen backdrop eller logo.** Forventa: serien sin backdrop og logo blir brukt. Ingen tom hero. Test i oppgåve 1.
4. **Rask D-pad-rulling gjennom 20 kort.** Forventa: backdrop blir lasta berre for kortet der fokus stoppar (≥ 250 ms). Test i oppgåve 7.
5. **Eit Watch Next-innslag med intent til ein annan app.** Forventa: blir avvist. Innslaget opnar berre sin eigen pakke. Test i oppgåve 9.

  - `@Serializable data class Ratings(val community: Double? = null, val criticPercent: Int? = null, val official: String? = null)`
  - `@Serializable data class ItemArt(val backdrop: String? = null, val logo: String? = null, val poster: String? = null, val wide: String? = null)`
  - `@Serializable data class MediaItem(val id: String, val accountId: String, val type: ItemType, val title: String, val seriesName: String? = null, val seriesId: String? = null, val season: Int? = null, val episode: Int? = null, val year: Int? = null, val runtimeMinutes: Int? = null, val overview: String? = null, val ratings: Ratings = Ratings(), val progress: Float? = null, val art: ItemArt = ItemArt())`

Format: `"$base/Items/$id/Images/Backdrop/0?maxWidth=1920&quality=80&tag=$tag"` osb. med verdiane i Global Constraints. `tag` er URL-koda.
  - `object ItemParser { fun parseList(body: String, account: MediaAccount): List<MediaItem>; fun parseItem(obj: JsonObject, account: MediaAccount): MediaItem? }`. `parseList` tek både `{"Items":[…]}` og ein rein array (Latest). Felta blir lesne utan omsyn til stor/liten forbokstav (`Name`/`name`).
- Reglar som parseren må følgje (algoritme):
  - `type`: `Movie`→MOVIE, `Series`→SERIES, `Episode`→EPISODE, anna→OTHER.
  - `runtimeMinutes = RunTimeTicks / 600_000_000` (heiltal, null når 0 eller manglar).
  - `progress = UserData.PlayedPercentage / 100f` berre når 0 < p < 100.
  - `ratings`: `CommunityRating` (Double), `CriticRating` (Int), `OfficialRating` (trimma, null når tom).
  - `art.backdrop`: eigen `BackdropImageTags[0]` → `ParentBackdropItemId` + `ParentBackdropImageTags[0]`.
  - `art.logo`: eigen `ImageTags.Logo` → `ParentLogoItemId` + `ParentLogoImageTag`.
  - `art.poster`: MOVIE/SERIES eigen `ImageTags.Primary`. EPISODE: `SeriesId` + `SeriesPrimaryImageTag`.
  - `art.wide`: EPISODE: eigen `ImageTags.Primary` (`Primary`, `maxWidth=640`). Elles eigen `ImageTags.Thumb` → `ParentThumbItemId` + `ParentThumbImageTag` → backdropen ved `maxWidth=640`.
  - Element utan `Id` eller `Name` blir hoppa over.

  - `sealed class MediaError(msg: String) : Exception(msg) { class Unauthorized : MediaError("401"); class Unreachable(cause: Throwable) : MediaError("unreachable"); class Server(val code: Int) : MediaError("http $code") }`
  - `enum class Endpoint { RESUME, NEXT_UP, LATEST_MOVIES, LATEST_SERIES }`
  - `const val ITEM_QUERY = "Fields=Overview,ProductionYear,RunTimeTicks,OfficialRating,CommunityRating,CriticRating,ParentId,SeriesId&EnableUserData=true&EnableImageTypes=Primary,Backdrop,Logo,Thumb&ImageTypeLimit=1&Limit=20"`
  - `fun endpointCandidates(kind: ServerKind, endpoint: Endpoint, userId: String): List<String>`:
    - RESUME: Jellyfin `["UserItems/Resume?userId=$u&MediaTypes=Video&$ITEM_QUERY", "Users/$u/Items/Resume?MediaTypes=Video&$ITEM_QUERY"]`, Emby berre den andre.
    - NEXT_UP: `["Shows/NextUp?UserId=$u&$ITEM_QUERY"]` for begge.
    - LATEST_MOVIES / LATEST_SERIES: Jellyfin `["Items/Latest?userId=$u&IncludeItemTypes=Movie&$ITEM_QUERY", "Users/$u/Items/Latest?IncludeItemTypes=Movie&$ITEM_QUERY"]`, Emby berre den andre. SERIES bruker `IncludeItemTypes=Episode&GroupItems=true`.
  - `interface MediaServerClient { suspend fun resume(): List<MediaItem>; suspend fun nextUp(): List<MediaItem>; suspend fun latest(endpoint: Endpoint): List<MediaItem> }`
  - `class JellyfinEmbyClient(account: MediaAccount, token: String, http: OkHttpClient, identity: ClientIdentity) : MediaServerClient`. Prøver kandidatane i rekkjefølgje og går vidare berre ved 404. 401 → `Unauthorized`. IO-feil → `Unreachable`. Anna ≥ 400 → `Server`.
