# Sonos i Stova gjennom Home Assistant

Bestilling 3. november 2026: ein valfri Sonos-modul med eiga side, ikon, omslag,
avspeling og gruppering. Home Assistant er transporten; Stova eig TV-opplevinga.

- [x] 1. Datamodell og transport: identifiser Sonos frå registeret, eigne live-abonnement,
  medieblaing, koordinatorstyring og validerte avspelings-/gruppehandlingar. Test først.
- [x] 2. TV-side: romliste, stort omslag, metadata, avspeling, volum, kjelder,
  tilfeldig/gjenta, framdrift, gruppering og mediebibliotek med tilbakeveg. UI-testar.
- [x] 3. Aktivering under tilkoplingar, eige toppfeltikon og flis på Appar. Av som standard;
  ingen Sonos-kall når av, utan HA eller på barneprofil. Dokumenter arkitekturen.
- [ ] 4. Full einingstest/lint/bygg og visuell kontroll på Stova_TV (5580), òg store
  skrifter, feil/tomtilstand og D-pad. Ingen verkelege høgtalarar eller TV-ar i denne økta.
- [x] 5. Tillegg frå eigaren: valfri Sonos-kunst på Heim medan musikken spelar. Byt også
  heroen til musikktittel/artist, og gå tilbake ved pause/stopp/fråkopling/biletfeil. Av som
  standard, inga henting når valet er av. TV-lyd på ei Sonos-lydplanke sperrar bakgrunnen,
  også med gammal albumkunst og musikk i andre rom (`source=TV` / `x-sonos-htastream:`).
- [x] 6. Valfri Music Assistant gjennom HA, med eksplisitt kopling mellom Sonos-rom og
  MA-spelar. Same bibliotekflate for album, spelelister og favorittar; aktiv MA-kø styrer
  avspelingsknappane, medan volum og Sonos-gruppering framleis bruker Sonos-einingane.
- [x] 7. «Spelar no» ved sida av lys og andre widgetar, med omslag, tittel, rom,
  spel/pause og snarveg til sida. Eige innstillingsval, uavhengig av bakgrunnskunst.
  TV-lyd er berre synleg på Sonos-sida, ikkje i widgeten. Del live-abonnement med Heim-bakgrunnen.

Finpuss etter skjermprøva: fjern «Musikk i heile huset», demp sekundærknappane og
vis «Spelar no · romnamn» ved musikken, med eit lite avspelingsmerke ved aktive musikkrom.

Design: Stova sine matte temaflater, stort kvadratisk omslag til venstre for avspelinga,
rom i ei eiga venstre kolonne, tydeleg gruppepanel og bibliotek som eiga underside.
Lime berre på handlingar/val. Alle tekstar på nynorsk og engelsk. Ingen polling i bakgrunnen.

Avgrensing: musikktenester og bibliotek følgjer Sonos-/Music Assistant-integrasjonane i HA. Innlogging,
oppsett av høgtalarar og abonnement på musikktenester skjer i Sonos/HA. Verkeleg lyd,
gruppering og albumkunst frå eigaren sitt system må seinare prøvast med løyve frå eigaren.

Kjelder: https://www.home-assistant.io/integrations/sonos/ og Home Assistant core sine
`media_player`- og `sonos`-komponentar (lesne 2026-11-03).
Music Assistant: https://www.home-assistant.io/integrations/music_assistant/ og
`homeassistant/components/music_assistant/media_player.py` (`active_queue`, standard
medieblaing og avspeling). Ingen direkte Music Assistant-servertilkopling frå Stova.
