# Oppdag i Stova (Seerr gjennom Spole) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ei Oppdag-side, ei Heim-rad og ei tittelside i Stova som viser Seerr sitt «populært», «komande», søk og brukaren sine førespurnader, og lèt ein be om titlar, alt henta frå Spole.

**Architecture:** Spole (eige repo) får nye stiar på launcher-provideren han alt har, og eit `spole://discover`-lenkje; han gjer Seerr-kalla med si eiga innlogging og sine reglar. Stova får pakken `discover/` med modellar, ein blokkerande provider-klient (`SpoleDiscover`), eit repository med snapshot i minnet, ei radkjelde for Heim og tre `*Content`-skjermar (side, tittel, søk) under ein `DiscoverScreen` med eigen sidestabel.

**Tech Stack:** Kotlin, Jetpack Compose for TV, ContentProvider over `content://app.reelstack.launcher`, Coil 3, Robolectric/JUnit4 i begge repoa.

**Spec:** `docs/superpowers/specs/2026-11-01-oppdag-design.md`
