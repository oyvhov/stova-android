# Bibliotek og aldersgrense for bakgrunn

Bestilling: vel konkrete Jellyfin-bibliotek og høgaste aldersgrense for bakgrunnen,
slik at 18-årsfilmar ikkje blir viste. Valet gjeld per profil, også Emby-kontoar.

- [x] 1. Raud kontrakttest; modell og eksplisitt ratingtolking. Standard maks 15,
  ukjend alder skjult; alle bibliotek er forskjellig frå ingen valde.
- [x] 2. Bibliotekoppslag og avgrensa førespurnader. Same filter på spotlight,
  sesong, faste bilete, søk og buffer; tomt/feil gir aldri eit vidare utval.
- [x] 3. TV-venlege bibliotek-/aldersval, fokusretur og førehandsvising. Gamal
  bakgrunn blir fjerna straks filter eller profil endrar seg. Profilkopi bevarer mottakaren sitt filter.
- [x] 4. Full testar/lint/bygg og visuell kontroll; installer med -r og prøv på
  emulator-5580 og Shield med bevarte data. Ingen avspeling eller HA-handlingar.
- [x] 5. Oppdater arkitektur/spesifikasjon, rapport, ledger og HANDOFF; lokale commitar.

Berre root skriv/byggjer/prøver einingar. Underagentar gjer lesande review/research.
Ingen endring av tilgang eller aldersreglar på medietenaren; dette gjeld Stova sin bakgrunn/hero.
