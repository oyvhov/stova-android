# Appmenyen skal bli ståande etter langt trykk

Bestilling: langt trykk på appar opnar menyen, men han lukkar seg straks.

- [x] Gjenskap OK-hald og slepp med ekte nøkkelhendingar; legg til raud regresjon for menyvindauget.
- [x] Rett eigarskap til OK-trykket utan tidsbasert sperre som stel neste vanlege trykk.
- [x] Prøv appmeny på Heim og Appar på emulator, kontroller kort trykk, Meny, Back og databevaring; oppdater Shield.
- [x] Køyr relevante UI-/navigasjons-/design-testar, lint og bygg; dokumenter, commit og push.

Avgrensing: Shield viste YouTube under brukskontrollen. Ny APK er installert der, men
fysisk menyverifisering er ikkje fullført. Emulatoren bruker framleis ekte profilar og bibliotek.
