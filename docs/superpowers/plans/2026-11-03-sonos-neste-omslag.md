# Sonos: klargjer neste omslag

- [x] Finn neste spor i den aktive Music Assistant-køen. Sjekk spelar, kø og spor før førehandshenting, og bruk det dekoda omslaget først når sporet er aktivt.
- [x] Hald førre omslag synleg til neste er dekoda. Ton inn det nye i eit grafikklag, respekter redusert rørsle, og demp bakgrunnskunsten med 14 % temafarge.
- [x] Køyr kø-, transport-, skjerm- og designtestane. Kontroller eit låtbyte med forseinka bilete og bygg TV-APK-en.

Vanleg Sonos gjennom HA har ikkje bilete i køresponsen. Sida kan framleis
tone over til det nye omslaget når avspelingstilstanden leverer det.
Prøv ekte kø på Shield eller Loftet berre etter eiga bestilling.
