# Projectivy Icon Pack og eige Spole-merke

Brukaren vil bruke `SicMundus86/ProjectivyIconPack`, ha eit Spole-ikon i same stil og kunne vise ikon utan kortbakgrunn.

- [x] Raude testar for transparente Spole-wordmark og korrekt sideforhold på breie pakkeikon.
- [x] Installer offisiell APK separat på emulator-5580; verifiser oppdaging, mapping og veljar med ekte appar.
- [x] Lag eige transparent SVG/Android-vektor/PNG med Spole-merke og wordmark. Legg supplementet i Stova sin Projectivy-katalog og automatisk fallback for begge Spole-pakkane.
- [x] Val for bakgrunn på appkort, med transparent utgangspunkt når Projectivy blir vald; ingen endring av originalpakken.
- [x] Full suite, lint, bygg og visuell prøve med ekte data. Lagre kjelde/versjon/hash, bilete, rapport og lokal commit.

Originalpakka har inga lisensfil i rotlista som vart lesen. APK blir installert frå offisiell release;
han skal ikkje leggjast i Stova-repoet eller signerast om. Eigne Spole-ressursar kan følgje Stova.
Ingen Shield-installasjon eller push i emulatorflyten.
