# Installer siste Stova og Projectivy på Shield

Ny uttrykkeleg bestilling 25.10.2026: «Installer alt på Shield for meg».
Dette omfattar siste testa Stova med roleg fokus, framsideredigering, retry og Spole-supplement,
og offisiell Projectivy Icon Pack. Den nye bestillinga opnar for installasjon på Shield.

- [x] Verifiser NVIDIA Shield `192.168.10.182:5555`, lokale APK-hashar, testresultat og profil-/kontodata før installasjon.
- [x] Installer/oppdater begge APK-ar med `install -r`, og kontroller dei installerte filene.
- [x] Vel Projectivy og transparente appkort i Shield-profilen. Bevar resten av profilen, favorittar, ikonoverstyringar og kontoar.
- [ ] Opne Stova og kontroller data, D-pad, langt OK og Spole-ikonet på Shield. Returner til Heim.
- [ ] Kontroller at kontoar og andre profilfelt er uendra. Dokumenter og commit lokalt.

Ingen datatømming, avinstallasjon, HA-styring, endring av standardlauncher eller push.
