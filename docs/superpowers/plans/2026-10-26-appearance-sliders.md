# Skyveknappar for utsjånad

Bestilling: fleire sliderar, mellom anna prosent bakgrunn på appkort.

- [x] 1. Raud UI-kontrakt; felles TV-skyveknapp med eitt fokuspunkt, direkte mus/berøring,
  OK-justeringsmodus, klemde endepunkt og fokusretur. Prosent og tal er synlege.
- [x] 2. Profilverdiar og integrasjon: appkort 0–100 %, dimming 0–100 %, hjørne 0–32,
  kortavstand 0–40 og spotlight 5–60 s. Bevar eldre felt og faktisk utsjånad.
  Same teikning i preview/Heim; ingen demping av ikon/tekst med bakgrunnsprosenten.
- [x] 3. Samanslå lagring under justering; siste verdi overlever rask retur/profilbyte.
  Regresjonar for piler, eldre JSON, visuell alfa, redusert rørsle og store skrifter.
- [x] 4. Full testar/lint/bygg, visuelt sjekka native bilete, installer med -r på
  emulator-5580 og Shield og prøv med bevarte profilar/kontoar. Ingen avspeling/HA-styring.
- [x] 5. Spesifikasjon, arkitektur, rapport, ledger, HANDOFF og lokale commitar.

Root er einaste skrivar/byggjar/einingsoperatør. Underagentar gjer lesande review.
